# Archived reports (historical, not current)

These documents describe the platform before the 2026-09-29 refactor. They are kept for history
only. Several statements in them are known to be wrong - for example that all 29 Beqaa
coordinates are unique (they are 11 village centres), that the ML pipeline merges themes by
village name (it used a nearest-neighbour join), and the published model accuracies (they were
in-sample). See `docs/architecture.md` and `docs/decisions.md` for the current system.
