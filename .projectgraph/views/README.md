## Mermaid sources

The `.mmd` files beside this one hold the same graph as text. They exist
because they diff usefully in Git and render on GitHub, neither of which
the self-contained HTML can do.

- [`overview.mmd`](overview.mmd) — project, systems and intent
- [`architecture.mmd`](architecture.mmd) — structure down to components and modules
- [`execution.mmd`](execution.mmd) — milestones and their members
- [`dependencies.mmd`](dependencies.mmd) — only the relationships that actually block
- [`verification.mmd`](verification.mmd) — what proves what
